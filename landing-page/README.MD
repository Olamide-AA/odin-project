# Landing Page

A single page marketing site built from a provided design mockup, as part of The Odin Project Foundations curriculum.

**Live demo:** https://olamide-aa.github.io/odin-project/landing-page/

## Overview

The page has four sections: a header with navigation and a hero block, an information section with four illustrated cards, a quote section, and a call to action above the footer.

## What I Practiced

- Flexbox for both horizontal and vertical layout
- Translating a static design mockup into working markup
- Managing spacing and alignment consistently across sections
- Working with a defined colour palette and type hierarchy
